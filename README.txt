CINNACLOUD — CINNAMOROLL WEBSITE

Files:
- index.html       Home page
- about.html       Cinnamoroll profile + timeline + creator note
- friends.html     Friends / character world
- gallery.html     Image gallery + click-to-expand modal
- funfacts.html    Fun facts + JavaScript quiz
- style.css        Main responsive stylesheet
- script.js        Mobile navigation, gallery modal, quiz, footer year

How to use:
1. Keep all files in the same folder.
2. Open index.html in Google Chrome, Microsoft Edge, or another browser.
3. Internet is needed for the Wikimedia Commons images in gallery.html.

Design:
Main palette is light pink + light blue, with white used as a neutral background/card color.
